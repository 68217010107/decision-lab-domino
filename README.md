# Decision Lab — เกมผลกระทบโดมิโน (Cloud / Real-time)

## จุดเด่น
- นักศึกษาใช้ Wi‑Fi คนละเครือข่ายได้
- ใช้ 4G/5G ได้
- อาจารย์สร้างห้องและ QR Code อัตโนมัติ
- นักศึกษาเข้าผ่าน QR และรหัสห้อง
- คำตอบส่งเข้า Dashboard อาจารย์แบบ Real-time
- มี 6 สถานการณ์ด้านการบริหารการศึกษา
- มีเหตุผลและ Reflection

## วิธีนำขึ้นออนไลน์ (ตัวอย่าง Render)
1. สร้าง repository บน GitHub และอัปโหลดไฟล์ทั้งหมด
2. เข้า Render แล้วสร้าง Web Service จาก repository
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Deploy
6. เปิด URL HTTPS ที่ได้
7. อาจารย์เปิด URL -> สร้างห้อง -> QR Code จะสร้างจาก URL จริง
8. นักศึกษาจาก Wi‑Fi ใดก็ได้สแกน QR แล้วเข้าห้อง

## หมายเหตุ
ต้อง Deploy ก่อนจึงจะใช้ข้ามเครือข่ายได้จริง ไฟล์นี้ไม่จำเป็นต้องมีฐานข้อมูล เพราะข้อมูลห้อง/คำตอบเก็บในหน่วยความจำของเซิร์ฟเวอร์ระหว่างกิจกรรม
